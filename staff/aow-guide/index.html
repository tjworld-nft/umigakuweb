実技の共通作法

スキルは全部この1サイクルで回す

3本のどのスキルも、進め方は同じです。順番を崩さなければ、初めての講習でも形になります。

  1. 1
    言う（ブリーフィング）

    何を・なぜ・どうやって・合格の目安。合格の数字は必ず口に出す（60秒・±1m、15m／6m／8m）。

  2. 2
    見せる（デモ）

    ゆっくり、少し誇張して、生徒全員が見える角度で。自分が達成条件どおりに動く。デモが速いと生徒も速くなる。

  3. 3
    やらせる（1人ずつ）

    他の生徒には待機位置を決めておく（砂地に膝をつかず、フィン先だけ接地のうつ伏せ、または中性浮力）。

  4. 4
    見る（評価）

    達成条件の言葉で見る。「できた／できていない」を自分の中ではっきり決める。曖昧なら、もう一度やらせる。

  5. 5
    返す（肯定→修正1つ→もう一回）

    まずOKサイン。直す点は1回に1つだけ合図で伝えて、再挑戦させる。できたらしっかり褒める（水中でも拍手でよい）。

立ち位置と管理

  • 手が届く距離：水面の浮力チェック・潜降・ホバリングは、生徒の正面か斜め前で腕1本分。BCDの肩ベルトをつかめる位置。
  • 全員が視界に入る位置：スキルをやる生徒と待機の生徒が同時に見える所に自分を置く。背中を向けない。
  • ナビは後ろ・やや上：チームの判断に介入しない。迷わせてよい。危険なとき（ボート航路・深度超過・残圧）だけ止める。
  • 中断の基準：耳抜き不良、パニックの兆候（目が泳ぐ・呼吸が速い・レギュを触る）、ターン圧到達、透明度や海況の悪化。迷ったら浮上して仕切り直す。

知識開発

ナレッジリビューが終わっていないと、ダイブのクレジットは出せない

各アドベンチャー・ダイブの前に、そのダイブを安全に終えるための知識を復習します。方法は3つのどれでもよい。①プレダイブ・ブリーフィングで復習 ②体系的なディスカッション ③該当するナレッジリビューを修了させる。

署名の条件生徒がナレッジリビューを修了し、それを復習した場合のみクレジットを認める。アドベンチャー・ダイブ・トレーニング・レコードに記入して署名するか、別の方法でナレッジリビューとダイブの両方の修了を記録する。アンサーキーはPADI Pros' Siteにある。
当日の運びかたeLearningで該当セクション（Peak Performance Buoyancy／Fish Identification／Underwater Navigation）が終わっているかを集合時に確認。未修了ならダイブ前にブリーフィングで要点を復習し、ナレッジリビューをその場で終えてもらってから潜る。「Thinking Like a Diver」は理想は最初のダイブ前、遅くとも認定前に修了していればよい。
Thinking Like a Diver

毎回のダイブに「経験豊富なダイバーの視点」を織り込む

マニュアルはこれを「ダイブ前・最中・後にあてはめる」と書いています。やることは3つに分けると簡単です。

  • ブリーフィングで：状況認識・タスクの管理・よいダイバーとしての行動、この3つに関するリマインダーを入れる。
    例「ホバリング中も30秒に1回はバディを見る」「コンパスを担当する人は深度と残圧を相方に任せる。任せると決めたことを潜降前に言い合う」「砂地は膝をつかない。フィンを上げる」
  • ダイブ中で：自分がその行動をデモンストレーションする。生徒はインストラクターの動きをそのまま真似します。
  • デブリーフィングで：質問を投げかけて、生徒自身に理念をあてはめさせる。答えを言うのではなく訊く。
デブリーフィングの質問ストック
  • 状況認識：「バディの残圧を最初に確認したのはいつ？」「深度がずれたと気づいたきっかけは？」
  • タスク管理：「数えること・方位・バディ、3つをどんな順番で回した？」「一番おろそかになったのはどれ？」
  • よいダイバーの行動：「水底や生き物に近づきすぎた場面はあった？」「次のダイブで1つだけ変えるなら何？」

Briefing outline

共通の台本

  1. コンディションの評価。波・うねり・流れ・透明度・水温・潮汐。今日は◯◯なので、ここに注意しますと、生徒にも判断を見せる。

  8. 通信と緊急手順。使うハンドシグナル、はぐれたら1分探して浮上、緊急時の合図、現地の規制で必要な事項。

流線形とウエイト見積もり

10分

やる内容

達成条件1と2をここで済ませる。器材を組んだ状態で1人ずつ回る。

生徒の動き

  1. ホースを全部引っ張ってみる。SPGは胸の近く、オクトパスは見える位置で引けば外れる留め方。スレートなどはポケットへ。
  2. 下の表で自分のウエイトを計算し、スレートに書く。
  3. ウエイトをどこに置くか決める（ポケット／ベルト、前後左右）。
  4. ダンプバルブを全部触って位置を覚える。
  5. 目を閉じて30秒、水平に浮いている自分をイメージする。

あなたの動き

  1. 1人ずつ「引っ張ってみて」。ぶら下がりがあれば留め直させる（自分で留めさせる）。
  2. ウエイト量を本人に言わせ、表と合っているか見る。海の経験値があればそれも足す。
  3. 手渡し用の小さいウエイト（0.5〜1kg）を2〜3個、自分のポケットに入れておく。

ウエイト見積もり（海水・平均体型）

体重を入れると目安が出ます。浮力チェックで確定するための出発点。この数字を正解にしない。

SKILL 1 / 水面

浮力チェック（プレダイブ）

5分

やる内容

達成条件3。足のつかない深さ（または膝を曲げれば垂直に浮ける深さ）で、1人ずつ。

全装備・BCD空・静止・通常呼吸。フィンで踏ん張らない。

生徒の動き

  1. レギュレーターで呼吸しながら、足のつかない所へ。最初はBCDに空気を入れておく。
  2. 合図でBCDの空気を完全に抜く（インフレーターを上げて排気、またはダンプ）。
  3. 普通に呼吸しながら垂直に浮く。足は動かさない。
  4. 「普通に吸って、止めて」→ 目の高さに水面が来るか。
  5. 「吐いて」→ ゆっくり沈み始めるか。

あなたの動き

  1. 生徒の正面、腕1本の距離。肩ベルトをつかめる位置。声で指示する（水面なのでレギュを外させてよい）。
  2. 目の高さより沈む → ウエイトを0.5〜1kg抜いて渡してもらう。浮く → 0.5〜1kg渡す。目の高さになるまで繰り返す。
  3. 決まったらウエイトをポケットに収めさせ、合計を言わせる。フルタンクなら終盤約2kg軽くなるので、目の高さぴったりなら＋1〜2kgを検討（SPガイドの考え方）。
  4. 次の生徒へ。待っている生徒はBCDに空気を入れて浮いて待つ。
合格の目安　息止めで目の高さ、吐くとゆっくり沈み始める。
うまくいかないとき
  • 沈まない → BCDに残気（インフレーターを高く上げて排気させる／ダンプ）、フィンで踏ん張っている（足を止めさせる）。
  • すぐ沈む → 重すぎ。1kgずつ抜く。
  • スーツが新しくて浮く → 見積もりより多く要る。慌てず足す。
SKILL 2

潜降と慣らし

3分

やる内容

達成条件4の前半。5ポイント潜降で、フィンを使わず息を吐くだけで沈む。

生徒の動き

  1. 合図 → 方向確認 → BCD排気 → 時間確認 → 耳抜きしながら吐いて潜降。
  2. フィンは動かさない。沈み始めたらそのまま、耳抜きを続ける。
  3. 3〜6mで止まって、バブルチェックと慣らし（呼吸を整える）。
  4. 水底が近づいたらBCDに少量ずつ空気を入れて、着底せずに止まる。

あなたの動き

  1. 生徒のすぐ横、やや下で顔を見る。速すぎたら「止まって」、沈まなければ「息を吐いて」。

ホバリング60秒

10分

やる内容

達成条件6。呼吸だけで、±1m以内、60秒。1人2〜3回できる時間を取る。

生徒の動き（やり方）

  1. 中性浮力の状態から少し多めに吸って、水底から50cm〜1mまで浮き上がる。
  2. 姿勢は水平（またはあぐら）。手はBCDの前で組むか胸の前。フィンは止める。
  3. 吸うと少し上がり、吐くと少し下がる。上がり始めたら早めに少し吐く、下がり始めたら早めに少し吸う。反応は遅れて来るので、連続して操作しない。
  4. 息は止めない。目いっぱい吸った状態で小さく呼吸を続けることはある。
  5. 視線は正面の岩や自分の深度計。バディも時々見る。

  1. 自分がデモ。60秒、自分の深度計で深度を一定に保ちながら、生徒の目の前でホバリング。息を止めていないことが気泡で分かるように。
  2. 「あなたの番」→ 生徒が浮き上がって止まったら、自分のコンピューターのタイマー（または秒針）で計り始める。
  3. 自分は同じ深度でホバリングして基準になる。生徒の目の高さが、自分の目の高さから上下1m（自分の身長分に達したらアウト）を超えないかを見る。

うまくいかないとき

  • 上がり続ける → 「息を吐いて」。続くならワンプッシュ排気。上がり始めが遅れて見つかるのが原因。
  • 体が立つ → ウエイトが下に集まっている。次のスキルで配置を試す。
  • 気泡が途切れる → 息止め。「息を吐いて」→ 陸で「吸った状態で小さく呼吸」を練習。
  • フィンが動く → 「キックを止めて」。多くの人はフィンで自分を持ち上げている。

知識の補強（生徒に伝える要点・自分の予習）

なぜ「科」で見るのか

種類が多すぎて、いきなり種名では覚えられない。同じ科は体形・ヒレの位置・泳ぎ方・暮らす場所が似ている。グループを決めてから色や模様で種を絞ると、図鑑のどこを開けばいいか分かる。

観察の5ポイント

  • 大きさ：手のひら、フィン1枚など自分の物差しで。
  • 形：円盤状か紡錘形か細長いか。尾の形、ヒレの位置。
  • 色と模様：バー＝背から腹へ走る縞、ストライプ＝頭から尾へ走る縞。スポット、目の周りの線。
  • 行動：群れる／単独、中層でホバリング／底に座る、穴から顔、砂に潜る。
  • 生息場所：砂地・岩場・海藻・中層・穴、そして水深。

幼魚と成魚、オスとメスで色が全く違う種がある。深度で色が消えるので、色だけで決めない。

責任ある行動（達成条件4）

  • 触らない・持たない・追わない・囲まない・餌を与えない。
  • 中性浮力を保ち、着底しない。砂を巻き上げない。
  • 器材をまとめる。
  • 逃げる・威嚇するは近づきすぎのサイン。止まって距離を取る。

やる内容

生徒の動き（やり方）

  1. 持ち方：両手持ち＝顔の前で両腕を伸ばし、体の中心でお椀状の手にコンパス（最も正確）。腕装着＝付けた腕を曲げ、中指をもう一方の伸ばした腕の肘のくぼみに。コンソール＝ラバーラインを進行方向に、両ひじを脇に。

  3. 目印は「組み合わせ」で覚える：右に岩壁・水深8m・30キック。砂紋の向き、光の方向、深度の増減も使う。
  4. 行きは、方向や位置の確認に必要なら浮上してよい。
  5. 目標に着いたら、方向確認で1回だけ浮上。来た道を逆にたどる。振り返って見た景色を思い出す。
  6. 「ここがスタート」と思う所で止まって浮上。

あなたの動き

  1. チームの後ろ・やや上で追従。迷っても介入しない（航路・深度・残圧だけ止める）。
  2. 戻って浮上したら、自分も浮上して、スタートブイからの距離を目で測る（15m＝ボート1艘分の目安を自分の中に持つ）。
  3. 15m以内なら「OK」。外れたら理由を聞き、目標ブイからやり直し。
  4. 次のチームへ。
合格の目安　15m以内。浮上は方向確認のときだけ。
うまくいかないとき
  • 目印が1つしかない → 「右に岩・深さ・キック数」の3点セットで覚え直す。
  • 深度が変わってしまう → 中性浮力（達成条件1）。深度が変わるとキック数も景色も変わる。
  • 浮上が多すぎる → 次の往復では「行き2回まで」と決める。
SKILL 3 / 核心

コンパス直線往復

10分

やる内容

達成条件4と5。方位を保って進み、浮上せずに逆方位で戻る。6m以内。2人ともコンパス係をやる。

生徒の動き（やり方）

  1. 水面で、コンパス係が目標（ブイ、または岸の目標）にラバーラインを向けて方位を取る。距離係が距離を決める（例：30m＝40キック）。
  2. 潜降。中性浮力を取ったら、コンパス係が方位を確認して出発。
  3. 両腕を伸ばしてコンパスを体の中央に、水平に。コンパス越しに前を見る。距離係がキックを数え、深度と残圧も見る。
  4. 所定のキック数で止まる。浮上しない。ベゼルを180°回して逆方位をセットし、体ごと向きを変えて針を挟む。
  5. 同じキック数で戻る。止まって浮上。
  6. 役割を交代して、もう一往復。

あなたの動き

  1. チームの後ろ・上から。要所で「コンパスを水平に」「体ごと」を合図（コンパスを指してから手のひらを水平に／自分の体を回して見せる）。
  2. 折り返しで止まっているか、浮上していないかを見る。
  3. 浮上したら自分も浮上し、スタートブイからの距離を判定。6m以内で「OK」＋役割交代の合図。外れたらもう一往復。
  4. 両方の生徒がコンパス係で合格するまで。
合格の目安　6m以内、浮上なし、正しい持ち方で方位を維持。2人とも。
うまくいかないとき
  • 少しずつ曲がる → コンパスが傾いている、またはラバーラインが体の中心に無い。両手持ちに変えさせる。
  • 針だけ見て前を見ていない → 「コンパス越しに前」。目の高さまでコンパスを上げさせる。
  • 逆方位で体が回り切っていない → 止まって、針がマークの間に来るまで回してから出発。
  • 流れでずれる → 往復とも同じキック数なら戻るはず。ずれ方向を見て、次は少し上流側を狙わせる。
SKILL 4

四角形（または長方形）

10分

やる内容

達成条件6。30m×4辺、90°ずつ。8m以内。2人ともコンパス係をやる。

生徒の動き（やり方）

  1. スタートで、あなたが指定した1辺目の方位をセット。
  2. 30m（自分のキック数）進む → 止まる。
  3. ベゼルに90°足す（右回り）→ 体ごと回して針を挟む → 次の30m。
  4. これを4辺。最後の辺の終わりで止まって浮上。
  5. 役割交代で、もう1周（時間がなければ一辺20m）。

あなたの動き

  1. 1辺目の方位を指で示す（ブリーフィングで伝えた数字）。
  2. 各角で「止まっているか」を見る。泳ぎながら手首を回したら「止まって」。
  3. 浮上したら判定。8m以内で「OK」。外れたら、ずれた辺を推測して伝え、もう1周。
合格の目安　8m以内。角で止まってセットしている。2人とも。
うまくいかないとき
  • 1辺だけ長い・短い → 数え忘れか、流れ。往路と復路で同じ辺なら流れ。
  • 角で回り過ぎ → 針がマークを通り過ぎている。止まって針が落ち着くまで待つ。
  • 時間がない → 一辺20mで実施（「一辺30mが望ましい」であって絶対条件ではない）。

浮上・安全停止・エキジット

5分

生徒の動き

  1. 1分に18m以下。5mで3分。水面でプラス浮力。
  2. 陸に上がったら、スレートの数字をすぐログに写す（消える前に）。

あなたの動き

  1. ライン・ブイを回収（またはアシスタントに）。
立ち位置（2案・吉田と当日決める）
  • SPガイドの標準：インストラクターは水面。バディチーム別に色分けしたフロートを曳かせ、水面のブイの動きで進行と間違いを判断する。誤差の判定が客観的。

デブリーフィング全文

数字を一緒に計算しながら。10分

Navigation debriefing

台本

  1. 肯定。コンパス往復、2回目で4mでした。角で止まれていたのが良かった。自然ナビで浮上が1回で済んだのは、目印を組み合わせで覚えていたからです。
  2. 物差しの計算。30mが何キックだった？ 何秒？→ 下の計算で1キックと1秒の距離を出して、スレートからログへ。この数字は、フィンやスーツが変わると変わります。時々測り直してください。
  3. 各課題の振り返り。自然ナビは何m外れた？ 何が効いた？（目印・深度・キック数）コンパス往復は？ ずれた方向は？ 流れのせい？ 持ち方のせい？四角形はどの辺が怪しかった？
  4. 達成条件の確認。6項目を読み上げ、2人ともコンパス係で合格しているかを確認。未達は次のダイブの最初に再挑戦。
  5. Thinking Like a Diverの質問。数えている間、バディをどう確認した？違和感を覚えた瞬間はあった？ そのとき何をした？次に同じ場所で潜るなら、どの目印を使う？
  6. ログ。キック数・秒数・各課題の誤差・使った目印を書かせる。署名。

距離の物差し（一緒に計算する）

数字を入れると、1キックと1秒あたりの距離、そして30m・60mに必要なキック数と秒数が出ます。
知識の補強（生徒に伝える要点・自分の予習）

距離を見積もる5つの方法

  • キックサイクル：片足の上下1回を1。30m÷キック数＝1キックの距離。フィンが変わると変わる。
  • 経過時間：30m÷秒数＝1秒の距離。途中で止まると狂う。
  • シリンダー圧力：消費量を区間で割る。目安。
  • アームスパン：両腕を広げた長さ≒身長。視界が悪いときや短距離で正確。
  • 目盛り付きライン：最も正確だが長距離には向かない。

ダイブ前の観察4つと、自然の手がかり6つ

ダイブ前：風・潮流・潮汐／太陽の角度／沖合の物体と地形／水底の地形と深度。水中：光と影／水の動き（流れ・サージ）／水底の構成（砂紋は海岸線に平行が多い。深くなる＝沖）／水底の傾斜／動植物の分布／音。

4つのパターンと6つのコツ

パターン：直線往復／正方形・長方形／三角形（120°ずつ）／円形（最も勧めない）。コツ：ダイブ前にバディと決める／イメージする／小さめでゆっくり／外れたらおおよその方角を思い出す／一方がナビ担当／時々浮上して確認。

エラーを防ぐ7つと、流れの補正

  • コンパスを信頼するが全面的には信頼しない。
  • 自然の手がかりでおよそ、コンパスで微調整。
  • 陸で練習してから。
  • バディと分担。
  • 流れを考慮する。
  • ゆっくり一定のペース。
  • ナビの限界を知る（小さな範囲でのみ効く）。

流れの補正：流れを無視して最後に修正／スタート地点を補正／方位を調整／意図的に片側へずらす／ポイントからポイントへ。AOWの1本では「片側へずらす」と「ポイントからポイント」を紹介するだけで十分。
