# モードA：ログ記事（ダイビングがあった期間）

実際に潜った日の現場レポート。読者はダイバーと、これから始めたい人。

## 使う材料

- 日付・場所（ビーチ／ボート・城ヶ島／宮川湾）
- 水温・透明度（**実際に記録がある場合のみ数値を書く。無いなら体感表現に留める**）
- 出会った生き物
- 天気・気温・季節感
- 現場の出来事（お客様のエピソードは実話のみ）

## 構成

1. **リード文**（見出しなし）
   - 「こんにちは、三浦 海の学校の吉田です。」で始める
   - 近況や季節感から入る自然な導入
   - 更新が空いていたならさりげなく触れる
   - 冒頭100文字以内に「三浦」「ダイビング」を含める
2. `## （季節・状況の見出し）` — 陸の天気・気温・海へ向かう気持ち
3. `## （海況の見出し）` — 例「今の三浦の海況」「三浦半島の春濁りとは」
   - 現象の背景や意味を初心者にもわかるよう説明
   - 見出しに地名（三浦・三浦半島）を入れる
4. `## 三浦の海で出会った生き物たち`
   - `###` 小見出しで1種ずつ紹介（下記「生き物紹介のコツ」参照）
5. `## （まとめ・メッセージの見出し）`
   - 読者へのメッセージ、次回への誘い
   - ライセンス取得や体験ダイビングへの自然な導線
6. `## 三浦 海の学校について`（固定フッター）

## 生き物紹介のコツ

名前だけで終わらせず、以下を1〜2つ加えて膨らませる。

- 見た目の特徴・色・形
- 生態や行動（宿主、食性、動きの特徴）
- 水中での見つけ方
- 撮影難易度や注意点
- 季節性（この時季に多い等）
- 「三浦の海で見られる○○」のように地名と結びつける

# 共通ルール（両モード）

## 文体・トーン

- **冒頭**：必ず「こんにちは、三浦 海の学校の吉田です。」で始める
- **一人称**：「僕」
- **文体**：ですます調。親しみやすく、でも信頼感がある口調
- **立場**：現役インストラクターとして実体験に基づいて語る
- **絵文字・記号**：使わない
- **文字数**：3,000〜4,000文字（固定フッター含まず）
- **段落**：Markdownの空行区切りで読みやすく

## 日付（date）

**記事の日付は、必ず書いたその日にする。** 1日に何本書いても全部その日の日付を入れる。
「前の記事と同じ日になるから」と翌日にずらしてはいけない（2026-07-30に指示）。

同じ日に2本目以降を出すとき、先に公開した記事より上に並べたい場合だけ、
`date: "2026-07-30T09:30:00.000Z"` のように時刻まで入れて調整する
（一覧・記事ページは日付しか表示しないので、時刻は並び順にしか影響しない）。
日付だけを書いた場合は投入CLIが `T09:00:00Z` を補う。

slug 末尾の日付も同じ日にそろえる。

## タイトル（title）

- 「三浦」「神奈川」「ダイビング」のいずれかを必ず含める
- 30〜40文字程度。読みたくなる表現＋キーワードのバランス
- 良い例：「春濁りの三浦でウミウシ三昧——神奈川・三浦半島ダイビングログ」
- 悪い例：「今日のダイビング日記」（キーワードなし）

## description

- 120文字以内。ターゲットKWを1〜2個自然に含める
- 検索結果のスニペットになる。クリックしたくなる文にする

## 本文中のキーワード配置

- 冒頭100文字以内に主要キーワード
- 各 `##` 見出しにキーワードを1つ以上（不自然にならない範囲で）
- 本文全体で「三浦」5回以上、「ダイビング」5回以上（詰め込みすぎない）

## 固定フッター

```markdown
## 三浦 海の学校について

三浦 海の学校は神奈川県三浦市のPADI公認5スターIDCセンターです。ダイビングライセンスの取得から、
ファンダイビング、SUPやスノーケリングなどのマリンアクティビティまで、初心者からベテランまで楽しめます。
開催は城ヶ島・宮川湾。京急三崎口駅から開催地まで無料送迎をご利用いただけます。

- [ダイビングライセンス取得コース](https://miura-diving.com/license/)
- [ファンダイビング](https://miura-diving.com/fun-diving/)
- [マリンアクティビティ](https://miura-diving.com/marine-activity/)
- [お問い合わせ](https://miura-diving.com/contact/)
```

リンクは記事内容に応じて2〜4個選ぶ。**内部リンクは必ず `https://miura-diving.com/` から始める絶対URL**
（投入CLIが相対パスを自動修正するが、最初から絶対URLで書くこと）。

## 絶対に守ること

- **お客様の声や反応を想像・捏造しない**。実話のみ
- **水温・透明度の数値を推測で書かない**。記録が無ければ体感表現に留め、「正確なところはご予約時に」と逃がす
- **他のスクールの悪口や、比較での貶めは絶対にしない**
- **「絶対安全」「100%大丈夫」などの断言は避ける**。安全にはリスクが伴う旨を誠実に書く
- **医療アドバイスはしない**。持病がある場合は医師に相談を、と書く
- 季節ルール（4月はドライスーツのみ等）は正確に反映する
- 旧諸磯住所（`三崎町諸磯1621` 等）は絶対に書かない。場所は「神奈川県三浦市」「城ヶ島・宮川湾」
