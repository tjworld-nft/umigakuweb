Course Outline

AOWは「できること」を増やす講習です

OWDで身につけた基本を使いながら、深度、方向感覚、浮力、観察力、ボートやドライスーツなどの経験値を広げていきます。

講習は2日間で合計5ダイブ。必須科目はディープダイビングとアンダーウォーターナビゲーションです。残り3ダイブは、基本的にPPB、魚の見分け方、ボートダイビング、ドライスーツダイビング、ナチュラリストから選びます。

1日目
基本の精度を上げる日
  • ナビゲーションやPPBなど、浅場で落ち着いて確認しやすい内容を中心に進めます。
  • コンパス、キック数、浮力、姿勢、呼吸の使い方を見直します。
2日目
環境に合わせて応用する日
  • ディープやボートなど、より幅のあるダイビングに挑戦します。
  • 安全停止、残圧管理、バディとの確認を丁寧に行います。

Required Dives

必須科目の考え方

どちらも「落ち着いて計画し、バディと確認しながら潜る」ための科目です。上手さより、確認の丁寧さを大切にします。

必須

ディープダイビング

  • 深くなるほど空気の消費が早くなり、無減圧時間も短くなります。
  • 色、浮力、残圧、体感の変化を観察します。
  • 深度・時間・残圧・浮上速度をこまめに確認します。

予習ポイント

深い場所に行くこと自体が目的ではなく、計画通りに潜って戻る判断力を身につけるのが目的です。

必須

アンダーウォーターナビゲーション

  • コンパスだけでなく、地形、砂紋、岩、光の向きも手がかりにします。
  • キック数や時間で距離感をつかみます。
  • 往復、四角形、簡単な探索ルートを練習します。

予習ポイント

Adventure Dives

選択科目は3つ

海況、季節、経験、目的に合わせて決めます。希望がある場合は事前に相談してください。

PPB 中性浮力

呼吸、姿勢、ウエイト量、フィンワークを整えて、砂を巻き上げずに止まる・進む練習です。

見ておくこと

  • 体を水平に保つ姿勢

名前を丸暗記するより、形、泳ぎ方、すみか、群れ方から仲間を見分ける練習です。

  • 岩場、砂地、海藻まわりなどの環境
  • 単独か群れか、隠れるか泳ぎ続けるか

ボートダイビング

ボート上での動き、エントリー、潜降、浮上、エキジットを落ち着いて行う練習です。

  • エントリー前の最終確認
  • 浮上後にボートへ戻る手順

  • 足に空気がたまる感覚

  • 触らない、追わない、着底しない意識

Learning Guide

各ダイブの学習要項

ここは「手順を覚える」よりも、なぜそのダイブを学ぶのか、どんなリスクがあり、どう考えると安全に楽しめるかを整理する場所です。

深度・時間・残圧はセットで考える

ディープでは、同じ海でも浅場とは条件が変わります。深くなるほど空気消費、浮力変化、無減圧時間、体への負荷が変わるため、ひとつの数字だけで判断しないことが大切です。

  • 深度を見るたびに、残圧と時間も一緒に確認する。
  • 浮上の余裕、安全停止、バディの状態まで含めて判断する。
  • 違和感があれば我慢せず、早めに浅くする。

ディープダイビング

深い場所へ行くための講習ではなく、深度が変わったときに判断を崩さないための講習です。

必須

する意味

18mより深い世界では、色の見え方、残圧の減り方、浮力、無減圧時間の感覚が変わります。AOWではその変化を実際に確認し、深いポイントでも落ち着いて計画通りに潜る考え方を身につけます。

主なリスク

  • 空気消費が早くなり、戻る余裕が少なくなる。
  • 無減圧時間が短く、予定外に長居しやすい。
  • 浮上速度が速くなりやすい。
  • 判断力や感覚がぼんやりすることがある。

安全に楽しむ考え方

  • 最大深度、滞在時間、浮上開始残圧を事前に共有する。
  • 深度を落とすほど、残圧確認の間隔を短くする。
  • 「まだ行ける」より「余裕を残して戻る」を優先する。
  • 浮上中は呼吸を止めず、深度変化を小さく刻む。

見ておく知識

  • 深度が増すと空気消費が増える理由。
  • 安全停止をする意味。
  • 色が吸収されて見え方が変わること。
  • ダイブコンピューターの深度、時間、浮上速度表示。

考えておくこと：深い場所で「あと少し見たい」と思ったとき、何を確認してから判断するべきでしょうか。

ナビゲーションは「方角」と「景色」の組み合わせ

コンパスは大切ですが、コンパスだけを見続けると周囲やバディを見落とします。砂紋、岩、海藻、光、流れ、深度変化を一緒に読むことで、水中の地図が少しずつ頭にできます。

  • 出発前に、帰りの方角と目印を決める。
  • 進む距離はキック数、時間、地形の変化で確認する。
  • 迷ったら動き続けず、止まってバディと情報を合わせる。

アンダーウォーターナビゲーション

水中で自分の位置を考え続け、チームで安全に戻るための基礎です。

必須

する意味

水中では視界が限られ、陸上より方向感覚が失われやすくなります。ナビゲーションを学ぶと、ガイドにただ付いていくのではなく、今どこにいて、どの方向に戻るのかを自分でも考えられます。

主なリスク

  • 目的地や帰り道を見失い、泳ぐ距離が増える。
  • 迷った焦りで残圧消費が早くなる。
  • コンパスに集中しすぎて深度やバディを見落とす。
  • 浮上場所がずれて、船や岸から離れる。

安全に楽しむ考え方

  • 出発地点の景色を振り返って覚える。
  • コンパス、地形、キック数を組み合わせる。
  • 不安になったら止まり、深度、残圧、方角を整理する。
  • バディと同じ情報を見ているか確認する。

見ておく知識

  • コンパスのベゼルとラバーラインの使い方。
  • 往復、四角形、三角形の考え方。
  • キック数と距離感の関係。
  • ナチュラルナビゲーションの目印。

考えておくこと：コンパスの方角が合っていても「何か違う」と感じたら、周囲のどんな情報を見直しますか。

浮力と観察力は、安全にも環境にもつながる

浮力が安定すると、疲れにくく、残圧にも余裕が出て、砂を巻き上げず、生き物にも近づきすぎません。魚の見分け方やナチュラリストも、まずは落ち着いた姿勢で観察することから始まります。

  • 止まる技術は、見る余裕を作る技術。
  • 海底に近いほど、フィンとゲージの位置に気を配る。
  • 生き物の行動が変わったら、距離が近すぎる合図。

PPB 中性浮力

上手に見えるためではなく、楽に、安全に、海を傷つけずに潜るための基礎です。

選択

する意味

中性浮力が安定すると、余計な動きが減り、疲れにくく、空気の消費も落ち着きます。水底を壊さず、生き物を驚かせず、写真や観察もしやすくなります。

主なリスク

  • 浮きすぎて急浮上につながる。
  • 沈みすぎて砂を巻き上げ、視界を悪くする。
  • サンゴ、海藻、生き物に接触する。
  • 手で泳ぐ癖がつき、姿勢が崩れる。

安全に楽しむ考え方

  • BCDに頼りすぎず、呼吸の変化を待つ。
  • 水平姿勢を意識し、足先とゲージの位置を見る。
  • 着底する前に一呼吸早く調整する。
  • 止まれないときは、まず動きを小さくする。

見ておく知識

  • 肺の浮力変化とタイムラグ。
  • ウエイト量と姿勢の関係。
  • 深度変化でBCD内の空気が膨張・収縮すること。
  • 砂地、岩場、海藻場での距離感。

考えておくこと：浮きそうになった瞬間、すぐに排気する前に何を確認すると落ち着けるでしょうか。

魚の見分け方

名前を覚える講習ではなく、観察の切り口を増やして海の中をもっと面白く見る講習です。

選択

する意味

魚を「知っている名前」だけで見ると、分からない魚は全部同じに見えます。体型、口、ヒレ、泳ぎ方、すみかを観察すると、名前が分からなくても仲間や暮らし方を推測できます。

主なリスク

  • 観察に夢中になり、深度や残圧確認が遅れる。
  • 近づきすぎて魚を追い込む。
  • 写真や観察で着底し、環境を傷つける。
  • バディとの距離が開く。

安全に楽しむ考え方

  • まず浮力とバディ位置を安定させてから観察する。
  • 魚の逃げ道をふさがない位置から見る。
  • 特徴は3つだけ覚えて、ログで調べる。
  • 見たい魚ほど、追わずに待つ。

見ておく知識

  • 体型、尾びれ、口の向きで暮らし方が見えること。
  • 砂地、岩穴、海藻、群れなどのすみ分け。
  • 幼魚と成魚で色や模様が変わること。
  • ログに残す観察メモの書き方。

考えておくこと：名前が分からない魚を見たとき、あとで調べるために何を覚えておくとよいでしょうか。

ボートダイビング

船から潜る楽しさと、船上・水面・浮上後の安全管理を学ぶ講習です。

選択

する意味

ボートを使うと、ビーチから届きにくいポイントに行けます。その分、船上の動線、エントリー、集合、浮上場所、エキジットなど、水中以外の判断も大切になります。

主なリスク

  • 船上で器材につまずく、転ぶ。
  • エントリー後に集合が遅れる。
  • 流れで船やブイから離れる。
  • 浮上後、船に気づかれにくい位置に出る。

安全に楽しむ考え方

  • 船上では荷物を小さくまとめ、通路を空ける。
  • エントリー前にマスク、レギュレーター、残圧、給気を確認する。
  • 水面ではすぐにOKサインを出し、集合場所へ向かう。
  • 浮上場所と合図、緊急時の手順を事前に聞く。

見ておく知識

  • ジャイアントストライドなどのエントリー方法。
  • 潜降ロープ、ブイ、アンカーラインの役割。
  • 水面シグナルと浮上後の待ち方。
  • 船酔い対策と水分補給。

考えておくこと：浮上した場所が船から少し離れていたら、まず何をして自分の位置を知らせますか。

ドライスーツダイビング

寒い季節も快適に潜るために、スーツ内の空気と体温管理を学びます。

選択

する意味

ドライスーツは体を濡らしにくく保温性があります。冬や春の海を楽しめる一方で、スーツ内の空気が浮力に影響するため、ウェットスーツとは違う考え方が必要です。

主なリスク

  • スーツ内の空気が足に移動し、姿勢が崩れる。
  • 排気が遅れて浮きやすくなる。
  • 首や手首から水が入る。
  • 暑さ、寒さ、締め付けで疲れやすくなる。

安全に楽しむ考え方

  • 給気は「締め付けを取る程度」から始める。
  • 浮上前から少しずつ排気を意識する。
  • 足が浮く感覚が出たら、姿勢を戻して落ち着く。
  • 陸上で暑くなりすぎないよう準備の順番を考える。

見ておく知識

  • 給気バルブと排気バルブの位置。
  • スーツ内空気の移動と姿勢の関係。
  • インナーの厚みとウエイト量。
  • 水没したときの落ち着いた対応。

考えておくこと：ドライスーツで急に足が軽く感じたら、慌てて泳ぐ前に何を整えるべきでしょうか。

ナチュラリスト

海の生き物と環境のつながりを見て、ダイバーとしての距離感を学ぶ講習です。

選択

する意味

海の中は、魚、海藻、砂地、岩、甲殻類、貝、季節の変化がつながっています。ナチュラリストでは、名前よりも「どこにいて、何をしていて、なぜそこにいるのか」を観察します。

主なリスク

  • 生き物を触る、動かす、追いかける。
  • 観察中にフィンやゲージが環境に当たる。
  • 小さな生き物に近づきすぎてストレスを与える。
  • 珍しいものに集中して周囲確認が減る。

安全に楽しむ考え方

  • 触らない、追わない、持ち上げない。
  • 観察前に浮力とフィン位置を整える。
  • 生き物の逃げ道を残す。
  • 写真を撮るときも、環境との距離を優先する。

見ておく知識

  • 岩場、砂地、海藻場で見られる生き物の違い。
  • 擬態、共生、群れ、なわばりの考え方。
  • 卵や幼魚の季節性。
  • ダイバーが環境へ与える影響。

考えておくこと：近づいた瞬間に生き物の動きが変わったら、それは何のサインでしょうか。

Study Notes

講習前に押さえるメモ

細かな数値や手順は当日も確認します。ここでは、各ダイブで意識する観点を整理します。

残圧管理

深度が増すと同じ呼吸でもタンクの空気は早く減ります。残圧は「まだある」ではなく、「戻る分、浮上する分、予備を残せるか」で見ます。

浮上

浮上はゆっくり、こまめに確認。安全停止中は深度を保ち、バディと周囲を見ます。浮上後もボートや岸まで気を抜きません。

バディ確認

エントリー前、潜降前、深度変更前、浮上前に、バディの位置と様子を見ます。AOWでは「自分ができる」から「一緒に安全に潜れる」へ視野を広げます。

観察

水中では、深度、時間、残圧、生物、地形、流れ、透明度など、見るものが増えます。全部を完璧に覚えるより、気づいたことをログに残す習慣が大切です。

ディープで起きやすい変化
色が変わって見える、空気の消費が早い、浮力調整が変わる、無減圧時間が短いなど。違和感があれば早めにインストラクターへ伝えます。
ナビゲーションで大切なこと
コンパスを見る時間と周囲を見る時間のバランスです。方角だけを見続けると、地形やバディを見失いやすくなります。
中性浮力の目標
止まる、浮きすぎない、沈みすぎない、手で水をかかない。呼吸と姿勢で小さく調整できる状態を目指します。
生き物を見る距離感
近づきすぎず、追いかけず、ライトや指示棒の使い方にも配慮します。生き物の行動が変わったら近すぎるサインです。
