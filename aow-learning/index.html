01

20 MIN. / BUOYANCY

PPB
力を抜ける浮力へ。

中性浮力は、止まれること。水底に触れず、呼吸と小さな操作で位置を保てる状態を目指します。

このダイブのゴール

水中で自分の浮力を診断できる

  • 適正ウエイトの確認手順を説明できる
  • BCD・呼吸・姿勢の役割を分けて考えられる
  • 浮き始め、沈み始めに慌てず小さく修正できる

WHY IT MATTERS

中性浮力は「きれいに浮く技」ではなく、安全を支える土台

深度を意図どおりに保てると、耳抜きに違和感があれば止まり、バディを待ち、残圧やコンピューターを落ち着いて確認できます。反対に浮力が崩れると、深度・ガス消費・バディとの距離・水底への接触が同時に崩れやすくなります。

01安全

予期しない潜降や急浮上を防ぎ、耳抜きや安全停止のために水深を選べます。

02ガスと体力

余分なキックと水の抵抗が減るため、呼吸が乱れにくく、計画したガスを使いやすくなります。

03環境

手や膝で支えず、フィンや垂れた器材を水底・生き物から離せます。

AOW SCOPE

今回行うのは、PPB SPの「ダイブ1」

適正ウエイトを決め、器材を流線形にまとめ、呼吸・BCD・ウエイト配置を使って安定した浮力とトリムをつくります。

THIS WEEKEND AOW / SPダイブ1
  • ウエイト量の見積もり・位置・配分
  • プレ／ポストダイブ浮力チェック
  • ゆっくりした潜降と中性浮力
  • 60秒ホバリングとトリム調整
FULL SPECIALTY SP認定は2ダイブ

今回はダイブ1の達成条件に集中します。PPBスペシャルティ認定には、さらにダイブ2の修了が必要です。

CORE 01

まずウエイト。次に姿勢。最後に呼吸。

重すぎるウエイトをBCDの空気で相殺すると、体積と抵抗が増え、操作量も大きくなります。上達の近道は「頑張って沈む」ことではなく、必要な重さを確認することです。

  1. 装備をすべて着ける使用するスーツ、シリンダー、アクセサリーまで条件を揃えます。
  2. BCDを空にして静止足の着かない場所で、通常の一呼吸を保ち、目の高さ付近に水面が来るか確認します。
  3. 息を吐いてゆっくり沈むインストラクターの管理下で少しずつ調整。終盤の軽くなったシリンダーでも再確認します。
当日ここを見ます ウエイトチェックは必ずインストラクターと安全を確保して実施します。自己判断でウエイトを外したり追加したりしません。

DIVE 1 PERFORMANCE

止まるだけでなく、範囲内に保つ

手やフィンで支えず、通常呼吸を続けながら深度を微調整します。器材や身体を水底・水面に触れさせないことも達成条件の一部です。

60秒ホバリング呼吸を止めずに維持
±1m深度の範囲1m以上浮き沈みしない
PRE＋POST浮力チェック開始前とダイブ後に確認

ウエイト量だけでなく、配置を変えて水平・垂直・頭が少し高い・足が少し高い姿勢を試し、自分のバランスを理解します。

THREE CONTROLS

操作は「大・中・小」で使い分ける

深度を変えると圧力でスーツやBCD内の気体体積が変わります。浮上中は膨張が次の浮上を招くため、早めに少量ずつ排気します。

大BCD全体の浮力を整える。短く操作して結果を待つ。
中姿勢・トリムウエイト配置と装備位置で水平姿勢をつくる。
小呼吸吸えば少し上がり、吐けば少し下がる。息は止めない。

THE PRINCIPLE

深度が変わると、変化が次の変化を呼ぶ

浮力は「押しのけた水の重さ」と「ダイバー全体の重さ」の関係で決まります。BCDやウェットスーツ内の気体が大きいほど多くの水を押しのけ、浮力は増えます。重さと浮力がつり合えば中性浮力です。

潜降

圧力が上がる

→

気体が圧縮

→

浮力が減る

→さらに沈みやすい
浮上

圧力が下がる

→

気体が膨張

→

浮力が増す

→さらに浮きやすい

だから大きく崩れてから一気に直すのではなく、変化の始まりを察知し、早めに少量の給気・排気を行い、反応を待ちます。呼吸による上下動には少し時間差があるため、連続して操作すると行き過ぎます。

CORE 02

「前と同じウエイト」で決めない

環境が変わった海水と淡水では浮力が違います。予想できても実際に確認します。
器材が変わったスーツ、シリンダー、BCD、アクセサリーの変更は浮力とトリムを変えます。
身体が変わった体重や体組成の変化、久しぶりのダイビングでは再確認します。
ガスを使ったアルミでもスチールでも、ガスを消費すればシリンダーは軽くなります。

多くのウエイトが必要な装備では、複数のウエイト・システムを使うと位置と配分の選択肢が増えます。ただし緊急時に捨てる方法を、バディと事前に確認します。

FAILURE CHAIN

「少し重いだけ」が、なぜ問題になるのか

  1. 01
    過剰なウエイト

    沈める安心感は得ても、中性にするためBCDへ余分な空気が必要になります。

  2. 02
    抵抗と姿勢の悪化

    膨らんだBCDや立ち気味の姿勢は水の抵抗を増やし、泳ぎ続けないと深度を保てなくなります。

  3. 03
    呼吸・ガス消費の増加

    運動量が増えると呼吸が大きくなり、浮力も揺れ、残圧の減りも速くなります。

  4. 04
    余裕の低下

    浮力操作へ注意を奪われ、バディ・深度・残圧・生き物を見る余裕が減ります。

水中の判断：まずキックを止める → 深度計と呼吸を確認する → 小さく操作する → 数秒待って結果を見る。大操作を重ねない。

浮力が崩れたとき、すぐインフレーターを押す前に一度キックを止めてみてください。フィンで自分を持ち上げていた、と気づく人はかなり多いです。

20 MIN. / NAVIGATION

ナビゲーション
方角と景色を重ねる。

コンパスだけを見続けるのではなく、地形・深度・光・移動距離と照らし合わせて「今どこか」を更新します。

このダイブのゴール

進む前に、帰るための情報を集める

  • コンパスを水平に保ち、進行方向を設定できる
  • キックサイクルまたは時間で距離を見積もれる
  • 自然の目印とコンパスの情報を照合できる

AOW SCOPE

今回行うのは、ナビゲーターSPの「ダイブ1」

距離を測り、自然の手がかりとコンパスを使って、浮上に頼らずスタート地点へ戻る練習をします。

THIS WEEKEND AOW / SPダイブ1
  • 30mを泳ぐキック数と時間の測定
  • ナチュラル・ナビゲーション
  • コンパスによる直線往復
  • 正方形または長方形パターン
FULL SPECIALTY SP認定は3ダイブ

今回はダイブ1の達成条件に集中します。複数回の方向転換やポイント再発見などは、後続ダイブでさらに深めます。

DIVE 1 PERFORMANCE

方向だけでなく、距離と誤差まで測る

通常のリラックスしたペースで30mを泳ぎ、自分のキックサイクル数と時間を求めます。この「自分の物差し」を各ナビゲーションで使います。

30m距離の校正キック数＋経過時間
15m内自然ナビスタート地点への誤差
6m内コンパス往復浮上せずに戻る
8m内四角形4辺を泳いだ後の誤差

キックサイクルは、両足の一連のフィンストロークを1回として数えます。速く泳いで数字を合わせるのではなく、普段の落ち着いたペースで測ります。

WHY IT MATTERS

ナビは「戻れる安心」を、計画に変える技術

ナビゲーションは目的地へ最短で行く競技ではありません。現在地と帰路を把握できれば、不安による呼吸の乱れ、予定外の水面移動、余分なガス消費を減らし、バディと同じダイブ計画を共有できます。

01ガス管理

出口までの距離が読めれば、残圧を「数字」ではなく帰れる余裕として判断できます。

02バディ

方向・距離・折返しを共有すると、一人が計器に集中しても二人で周囲を監視できます。

03落ち着き

迷ったときの手順を持つことで、焦って泳ぎ続ける、急いで浮上する判断を避けやすくなります。

潜降の時点からナビは始まっています 移動予定の方向を向き、フィート・ファーストで潜降します。コンパス担当と距離担当を決め、中層では互いに深度・バディ・残圧の確認も分担します。

CORE 01

コンパスは「向き」ではなく「進む線」をつくる道具

体が向いていても、手首だけ横を向けばコースはずれます。ラバーライン（進行線）を体の中心と進行方向に合わせ、コンパスを水平に保ちます。

N │ │
  1. ラバーラインを行きたい方向へ向ける
  2. ベゼルを回し、インデックスマークで磁針の北を挟む
  3. 腕だけでなく体ごと向きを変え、挟んだ状態を保って進む
よくある失敗 針だけを見て泳ぎ始める、コンパスが斜め、目標深度が変わる、キック数を数えていてバディを見なくなる。数秒ごとに「方角・深度・バディ」を巡回します。

ROUTE PATTERNS

往復と四角形

往路の反対は180°。四角形は各区間の終点でいったん止まり、コンパスを90°の新しい方位に設定してから体を向け、同じ距離を4辺進みます。流れやキック幅で誤差が出るため、自然の手がかりも照合します。

CORE 02

自然の目印は「変わりにくい組み合わせ」で覚える

地形岩壁、砂地との境目、傾斜
深度往路と復路の深度変化
光と影太陽の方向、岸側・沖側の明るさ
水の動き波、潮流、潮の干満、うねり
動植物群生する海藻や動かない生物の分布
音船、波、岸などの継続する方向性のある音

ダイブ前には波・潮流・潮汐、太陽の角度、沖合いの目標物や地形、予定深度を確認します。水中ではひとつに頼らず、「右に岩壁・水深8m・30キック」のように複数をセットで記憶し、振り返って帰り道の見え方も確認します。

MENTAL MAP

位置は、4つの情報を重ねて更新する

方向どちらへ

コンパス方位と地形の向き

距離どれくらい

キックサイクルと経過時間

深度どの層を

水深の増減と予定深度

目印何のそばを

底質、傾斜、岩、海藻の分布

キック数は流れ、装備、フィン、速度で変わり、時間も向かい潮や観察停止で変わります。どれか一つを「正解」とせず、例えば「方位90°・30キック・水深8m・砂地の縁」のように束ねます。情報が一致しないときこそ、コースを修正する合図です。

違和感があるとき：止まる → 中性浮力を取る → バディへ知らせる → 方位・深度・距離・目印を照合する → 合意した手順で再開する。分からないまま速く泳がない。

FAILURE CHAIN

コンパスに集中しすぎても、ナビは崩れる

  1. 01
    視線を固定

    磁針だけを見続け、深度・バディ・残圧の確認が止まります。

  2. 02
    姿勢と深度がずれる

    コンパスが傾き、立ち気味になり、同じ方位表示でも実際の進路が安定しません。

  3. 03
    距離の基準が崩れる

    流れへ対抗してキック幅や速度が変わると、校正したキック数と実距離がずれます。

  4. 04
    焦りが増える

    目印と合わなくなり、さらに泳いで修正しようとして帰路とガスの余裕を失います。

巡回の順番：方角 → 深度 → バディ → 残圧 → 前方。担当を分けても、各自が自分の安全確認を続けます。

20 MIN. / NATURALIST

ナチュラリスト
名前より、暮らしを見る。

AOWではナチュラリストSPのダイブ1に相当する内容を実施します。水中生物を受動的に観察し、環境を乱さず、3つの大きなグループを識別します。

このダイブのゴール

見つける・分ける・乱さない

  • 水生植物・藻類2種類以上を見つけ、一般名または学名で識別する
  • 無脊椎動物4種類以上、脊椎動物5種類以上を見つけて識別・観察する
  • 生き物と水底を守る受動的な観察姿勢を実践する

WHY IT MATTERS

名前を覚えるほどではなく、「見える情報」が増えるほど海は深くなる

生き物の形・居場所・行動を環境と結びつけると、同じポイントでも見落としていた関係に気づけます。その理解は観察を面白くするだけでなく、「近づく・触れる・着底する」が何を変えるかを自分で判断する土台になります。

01発見

名前を知らなくても、底質や行動から探す場所を予測でき、観察対象が増えます。

02判断

逃避・威嚇・摂餌などの行動変化を、こちらが離れるべきサインとして読めます。

03保全

水底や生き物を「背景」ではなく生活の場として見れば、接触を避ける理由が具体的になります。

CORE 01

生態系は「生き物＋環境」のチーム

生態学は、生き物とその生息環境の相互関係を学ぶこと。生態系は、生き物と環境がひとつの単位として機能している自然のまとまりです。水温、光、底質、隠れ場所、餌の有無が変われば、そこに暮らす生き物も変わります。

01水生植物・藻類

ワカメ、カジメなど。光合成を行い、隠れ場所や餌にもなります。

02無脊椎動物

ウミウシ、エビ、カニ、貝、ヒトデなど。背骨を持ちません。

03脊椎動物

硬骨魚、サメ、エイなど。体内に脊柱を持つ生き物です。

HABITAT生息場所

岩礁、砂地、海藻の間、穴など、実際に暮らす場所。

NICHE生態的役割

何を食べ、何に食べられ、どの時間・場所を使うかという「暮らし方」。

ADAPTATION適応

体形、色、殻、行動など、その環境で生き残り繁殖するのに役立つ特徴。

同じ場所にいるから同じ役割とは限りません。岩陰は、ある魚には休息場所、別の魚には狩り場、甲殻類には避難場所かもしれません。ナチュラリストは「いた」で終わらず、なぜそこにいた可能性があるかを、観察した事実から考えます。

WHY WATER IS DIFFERENT

水中では、見え方も動き方も変わる

陸上と同じ感覚で判断しないことがナチュラリストの第一歩。色だけで同定せず、形・動き・居場所を組み合わせます。

約800×密度

水は空気よりはるかに高密度。体を支える一方、動くと大きな抵抗になります。

COLOR光の減衰

深くなるほど色と明るさが失われます。ライトを当てた色だけでなく体形も確認します。

O₂酸素の分布

READ THE BEHAVIOR

「攻撃された」ではなく、理由を観察する

水中生物を人の性格に当てはめないこと。近づいた魚が噛む、威嚇する、逃げるときは、悪意ではなく縄張り・巣・仲間・子・自分を守ろうとしている可能性を考えます。

危険な怪物→ 多くは挑発や接触を避ければ距離を保ちます。

ペットのように無害→ 野生動物。触れず、退路をふさぎません。

動かない飾り→ カイメンやサンゴも生き物。着底や接触を避けます。

怒る・恨む→ 人間的に決めつけず、防御・摂餌・繁殖行動として考えます。

  3. 03

ディープ
深くなるほど、余裕は短くなる。

深い場所へ行くこと自体が目的ではありません。深度が変わっても、ガス・時間・浮上の余裕を失わずに判断するためのダイブです。

このダイブのゴール

最大深度ではなく、戻る余裕を計画できる

WHY IT MATTERS

深度は、複数の余裕を同時に小さくする

深くなるほど周囲圧が高くなり、同じ呼吸でもシリンダーのガスは速く減ります。同時にノンストップ・リミットは短くなり、低水温・暗さ・ガス昏睡の影響も判断を難しくします。ひとつの数字ではなく、変化が重なることを理解するのが重要です。

01ガス

残圧の減りが速くなるため、浅場より短い間隔で確認し、浮上分と予備を先に確保します。

02時間

ノンストップ・リミットまでの時間が短くなります。コンピューターの表示を「残り時間」として管理します。

03判断

暗さ、冷え、緊張、ガス昏睡が重なると、反応や判断が遅れる可能性があります。違和感は早めに共有します。

RECOGNIZE & RESPOND

異変は、水中で原因を当てるより浅くして伝える

深場で判断や反応が変わったとき、本人は気づきにくいことがあります。バディ同士で普段の反応を見て、短い合図に対する反応が遅い、妙に大胆になる、不安が強いなどの変化を見逃さないことが大切です。

GAS NARCOSIS ガス昏睡が疑われる

バディへ合図し、一緒に症状・徴候が消える深度まで浮上します。浅くなると改善するのが特徴ですが、そのダイブで再び深くしません。

ダイビングを中止し、すぐインストラクター／クルーへ伝えます。緊急用酸素、救急サービス、ダイビング医療への連絡を開始し、水中へ戻しません。

見逃さない症状・徴候 原因不明の痛み、しびれ、麻痺、めまい、異常な疲労、息切れ、発疹、ふらつき、咳、意識状態の変化などは、軽く見ず緊急対応します。

減圧症リスクを小さくする基本：自分のコンピューターを正しく使い、ノンストップ・リミットを越えない保守的な計画、管理された浮上、安全停止、十分な水分と体調管理を守ります。このAOWダイブで計画的な減圧ダイビングは行いません。

BEFORE DEPARTURE

早く来る目的は、急がず準備するため

  1. 余裕を持って集合案内された時刻に従い、一般的な目安として出航30分前までに乗船します。
  2. 置き場所を聞くクルーの指示前に器材を広げません。バッグは小さくまとめ、通路とエキジットを空けます。
  3. 器材を固定シリンダーをラックへ固定し、ゲージ・ホース・アクセサリーをはみ出させません。
  4. ブリーフィングを聞くエントリー、集合、潜降、帰路、浮上合図、ダイバー呼び戻し信号、エキジット、緊急手順を自分の船に合わせます。

SEASICKNESS

船酔いは我慢せず、早めに対策する

船酔いは集中力を奪い、嘔吐と脱水で体調を悪化させます。出航前に自分の対策を決め、症状が出たら早めにクルーへ伝えます。

PREVENT予防

十分な睡眠、適度な食事と水分、デッキの新鮮な空気、揺れの少ない中央付近、水平線を見ることが基本です。排気や細かい作業を避け、器材は早めに準備します。

RESPOND症状が出たら

クルーへ伝え、風下側で安全を確保し、水分を少しずつ取ります。閉鎖されたヘッドへ一人でこもらず、無理にダイビングしません。

酔い止め薬について 初めて使う薬をダイビング当日に試しません。眠気などの副作用があるため、事前に医師・薬剤師へダイビング予定を伝え、用法に従ってください。

LINES AROUND THE BOAT

ラインは、同じロープでも役割が違う

名称より「どこにつながり、何のために使うか」を見ます。ブリーフィングで使用するラインを指差して確認します。

01係留／アンカーライン

ボートを固定するライン。潜降・浮上の視標として使う場合があります。

02スイムライン

船尾から係留／アンカーラインへ移動するため、船の横に張られるライン。

03トレール／カレントライン

船尾から流れの下手へ伸び、船を通り過ぎたダイバーがつかまるライン。

04ギアライン

カメラや器材を一時的に保持するライン。使用はクルーの指示に従います。

05トリップライン

アンカーを外すためのライン。ダイバーが不用意に引いてはいけません。

ラインを使わない自由潜降：船から離れる方向を見失わず、バディとの位置と潜降速度を継続して確認します。浮上時は指定エリアを使い、頭上と船舶交通を確認し、プロペラ周辺へ近づきません。

BOAT ADVENTURE DIVE

海で実証する7つのこと

使う船の区画を理解し、船から離れる前から、全員が戻った点呼までをダイブとして考えます。

7項目船上からエキジットまで一連の手順として実施
5m / 3分安全停止ラインまたは環境に合わせる
SMB／DSMB水面シグナル各自携行し、指示どおり使用
  1. 区画を識別バウ、スターン、左右舷、器材収納、エントリー、エキジットを実際の船で示します。
  2. 安全器材を確認救急箱、酸素、AED、救命具、ダイブフラッグ、無線、消火器などの場所を確認します。
  3. 適切にエントリーバディと準備を合わせ、クルーのチェックを受け、その船に合う方法で入ります。カメラなどは必要に応じて入水後に受け取ります。
  4. ボートへ戻る計画したナビゲーションと、係留／アンカーラインなどの視標を使って帰ります。
  5. 安全停止5mで少なくとも3分。流れ、船の位置、他のダイバーにも注意します。
  6. 位置を知らせる水面でSMBを膨らませるか、ブリーフィングどおり浮上前にDSMBを展開します。
  7. 適切にエキジット順番を待ち、船とラダーを確保し、クルーの指示でフィンや器材を外します。

ENTRY & EXIT

急ぐほど、エントリーとエキジットは危なくなる

  1. 01
    準備のずれ

    バディより先に水へ入り、集合まで流れや波の中で待つことになります。

  2. 02
    確認の省略

    BCDの浮力、レギュレーター、マスク、水面の安全確認が抜けます。

  3. 03
    危険な待機位置

    エキジット時にラダーの真下へ入り、上のダイバーや器材が落ちる危険が増えます。

  4. 04
    船を離す

    フィンを外す前に船やラインを確保していないと、流れでエキジットから離れます。

エントリー：バディ準備 → クルー確認 → BCDへ必要な浮力 → レギュレーター → マスク保持 → 水面クリア → 入水後OK。
エキジット：プラス浮力 → 呼吸源をくわえる → ラダーの下を空ける → 船を確保 → 指示されてからフィンを外す。

INSTRUCTOR'S NOTE

船の手順は毎回同じとは限りません。知識がある人ほど、勝手に動かず「今日の船ではどうするか」を最初に確認します。
