# 地域別ダイビングライセンスページ テンプレート仕様

`/kanagawa-diving-license/index.html` をベースに、地域ごとの検索意図に応えるページを量産するためのテンプレート仕様です。
**コピペ量産を避けるため、「共通化する部分」と「必ず地域ごとに書き直す部分」を明確に分離**しています。

---

## 1. 共通テンプレート構成（セクション一覧）

ソース内の `<!-- ====== REGION-TEMPLATE: ... ====== -->` コメントがセクション区切りです。

| # | セクションID | 役割 | 地域差し替え |
|---|---|---|---|
| H | `<head>` meta / 構造化データ | SEO基盤 | **必須** |
| 0 | header / mobile-nav | 共通グローバルナビ | 共通（差し替え不要） |
| 1 | `hero.subpage-hero` | ファーストビュー | **必須** |
| 2 | breadcrumb | パンくず | **必須** |
| 3 | Section 1 `Merit` | その地域で取るメリット3つ | **必須（書き直し）** |
| 4 | Section 2 `Miura` | 三浦半島の海の特徴 | 共通（変更不要） |
| 5 | Section 3 `Check` (`#choose`) | スクール選び5チェック | 見出しのみ差し替え |
| 6 | Section 4 `For You` | ペルソナ6カード | "車を持っていない"カードだけ差し替え |
| 7 | Section 5 `Flow` (`#flow`) | 受講の流れ | 共通（変更不要） |
| 8 | Section 6 `Access` | アクセス表・送迎案内 | **必須（出発地順を並び替え）** |
| 9 | Section 7 `FAQ` | よくある質問 | **必須（質問の一部差し替え）** |
| 10 | Section 8 `Voice` | 受講者の声3件 | **必須（全差し替え）** |
| 11 | Section 9 `CTA` (`#cta`) | 電話・LINE・フォーム | 見出し／リード文のみ差し替え |
| 12 | Section 10 SEOテキスト | ページ下部テキスト | **必須（全書き直し）** |
| 13 | footer | 共通フッター | 共通（差し替え不要） |

### 2-3. 地域ペイン（ここが"刺さる訴求"の核）

各地域のユーザーが本当に気にしていることを、Section 1「メリット3カード」と Section 7「FAQ」で直撃します。

#### 横浜：`PAIN_POINT`
- 横浜には"海"のイメージがあるが実は潜れる海ではない（山下公園・八景島は眺める海）
- **訴求軸**：「横浜から最も近い"本物の海"」「京急1本・乗換なし」
- みなとみらい勤務者／横浜市民のライフスタイル（車なし電車中心）

#### 東京：`PAIN_POINT`
- 都内スクールは多いが「プール＝都内／海洋実習＝伊豆遠征」型が大半
- **訴求軸**：「1箇所完結型」「都内スクール比較で有利」「週末だけで完結」
- 平日都心勤務・週末レジャー層

#### 川崎：`PAIN_POINT`
- 川崎にはそもそもダイビングスクールが少ない
- **訴求軸**：「京急線1本で海までワープ」「工場シフト勤務の平日休みにも対応」
- 車派と電車派の両方に訴求

### 2-4. メリット3カード（Section 1）

| カード | 共通骨格 | 横浜の書き換え | 東京の書き換え |
|---|---|---|---|
| Card1 | アクセスの近さ | "横浜駅から京急線1本・45分、乗換なし" | "品川から京急線1本60分、東京駅75分、渋谷80分" |
| Card2 | 1箇所完結 / 本物の海 | "山下公園は眺める海、潜れる海は三浦" | "都内スクールに多い遠征型ではない" |
| Card3 | 取得後の継続性 | "横浜からならファンダイビングで通える" | "都心60分だから取得後もすぐ潜れる" |

### 2-5. FAQ 差し替え（Section 7 / 構造化データ FAQPage 両方）

**共通で残す質問**：「1人でも参加できますか？」「泳げなくても大丈夫ですか？」

**地域ごとに必ず差し替える質問**：
- Q1：その地域からの所要時間・交通手段を直接問う
- Q2：地域内の他スクールとの差分を問う
- Q3：その地域特有のライフスタイル質問
  - 横浜：みなとみらい・青葉区など広域から通えるか／車なしで通えるか
  - 東京：平日都心勤務・週末通学は可能か／都内スクールとの比較
  - 川崎：工場シフト勤務の平日講習に対応できるか

**重要**：`<script type="application/ld+json">` 内の FAQPage と HTML `<details>` は**必ず整合させる**こと（SEO上のペナルティ回避）。

### 2-6. 受講者の声（Section 8）

3件すべてをその地域在住者で差し替えます。

| 属性 | 横浜版 | 東京版 |
|---|---|---|
| 1人目 | 20-30代女性・横浜市西区（みなとみらい勤務） | 20-30代女性・港区（都内スクール比較済み） |
| 2人目 | 50代男性・横浜市中区（伊豆遠征型と比較した） | 50代男性・世田谷区（年齢不安の克服） |
| 3人目 | 30代男性・横浜市青葉区（田園都市線乗換ルート） | 20代男性・中央区（丸の内勤務・週末完結） |

各声の中に**地域固有の情報**（駅名／路線名／職場エリア）を必ず1つ入れ、地域特化感を出します。

### 2-7. CTAセクション見出し

| 変数 | 横浜 | 東京 |
|---|---|---|
| CTA h2 | 横浜から、ダイバーへの第一歩を踏み出そう | 東京から、週末だけでダイバーデビュー |
| CTA lead | 京急線1本45分、迷ったらまず無料相談を。 | 品川60分、1箇所完結でまずは無料相談から。 |

電話・LINE・フォームの3カードは**共通のまま変更しない**（導線の混乱を避けるため）。

### 2-8. SEOテキスト（Section 10）

4段落構成、1段落ごとに以下の役割：
1. **導入**：地域名＋アクセス＋ターゲット層を明示
2. **比較訴求**：その地域の他スクールと何が違うか（ここが地域ごとの核）
3. **環境訴求**：三浦半島の海・プール環境（ほぼ共通でもよい）
4. **取得後訴求**＋内部リンク（`/license/`, `/fun-diving/`）

## 3. 新しい地域ページを作るときの手順（川崎版を作る場合の例）

```bash
# 1. ベースをコピー
cp kanagawa-diving-license/index.html kawasaki-diving-license/index.html

# 2. 以下の順で書き換える（上から順にやると漏れにくい）
#   ① <title> / <meta description> / <meta keywords>
#   ② canonical / og:* / twitter:*
#   ③ 構造化データ（description / url / areaServed）
#   ④ FAQPage 構造化データ（HTMLのFAQと整合）
#   ⑤ BreadcrumbList 構造化データ
#   ⑥ hero の img alt / h1 / hero-sub
#   ⑦ breadcrumb HTML
#   ⑧ Section 1 Merit（h2＋3カード）
#   ⑨ Section 3 Check の h2
#   ⑩ Section 4 Persona の "車を持っていない" カード
#   ⑪ Section 6 Access 表（地域順に並び替え＋ハイライト行）
#   ⑫ Section 6 access-card の電車／車の文言
#   ⑬ Section 7 FAQ（地域特化の3問を差し替え）
#   ⑭ Section 8 Voice（3件全入れ替え）
#   ⑮ Section 9 CTA の h2 / lead
#   ⑯ Section 10 SEO テキスト（4段落）
```

### 品質チェックリスト（公開前）
- [ ] 「神奈川」という文字列が1つも残っていない（`Grep "神奈川"` で確認）
- [ ] `canonical` / `og:url` / BreadcrumbList URL が新しいslugになっている
- [ ] HTMLのFAQ と構造化データ FAQPage の質問・回答が一致している
- [ ] Section 1のメリット3カードが**その地域ならでは**の内容になっているか（他地域にコピペ可能な汎用文言になっていないか）
- [ ] 受講者の声3件すべてが新地域在住者になっている
- [ ] Section 6のアクセス表で**その地域の主要駅がハイライト行**になっている
- [ ] 画像altテキストに新しい地域名が入っている
