# 地域SEOページ テンプレート

## 概要

地域名を変えて横展開できるSEOページのテンプレートです。
コピペ感のない、各地域ごとにユニークなコンテンツを含むページを作成するためのガイドライン。

## 展開候補

| URL | ターゲットKW | ステータス |
|-----|------------|-----------|
| `/kanagawa-diving-license/` | ダイビングライセンス 神奈川 | 実装済み |
| `/kanagawa-diving-school/` | ダイビングスクール 神奈川 | 実装済み |
| `/tokyo-diving-license/` | ダイビングライセンス 東京 | 未実装 |
| `/yokohama-diving-license/` | ダイビングライセンス 横浜 | 未実装 |

## テンプレート構成（必須セクション）

1. **Hero** — 地域名を含んだ h1 + キャッチコピー
2. **地域ガイド** — その地域からのアクセスメリット + 三浦の海の魅力（2カラム）
3. **選ばれる理由** — 共通5項目（PADI/プール/アクセス/少人数/年齢）+ 地域固有の1項目
4. **エリア比較表** — 地域固有: ターゲット地域から通えるダイビングスポット比較
5. **取得の流れ** — 共通タイムライン
6. **料金プラン** — 共通料金表 + /owd-license/ リンク
7. **FAQ** — 地域固有 3問 + 共通 3問（/license/ のFAQと重複させない）
8. **受講者の声** — 地域在住者の声を優先表示
9. **アクセス** — 地域固有: ターゲット地域からの具体的な経路
10. **全コース案内リンク** — /license/ へ誘導（共通）
11. **CTA** — 電話・LINE・フォーム（共通）
12. **SEOテキスト** — 地域名を含んだ自然な文章（/license/ + /fun-diving/ リンク含む）

## 差別化のルール

**コピペ感を防ぐために、各地域ページで必ずユニークにする部分:**

- h1, title, description（地域名 + 検索意図に合わせた文言）
- FAQ の最低3問は地域固有の質問にする
- エリア比較表はターゲット地域の視点で構成
- アクセスセクションはターゲット地域からのルートを具体的に
- 受講者の声はターゲット地域在住者のものを優先
- SEOテキストは地域特有の文脈を含む

**共通で使い回してよい部分:**

- 選ばれる5つの理由（文言は共通）
- 取得の流れタイムライン
- 料金プラン表
- CTA（電話・LINE・フォーム）
- フッター

## 構造化データ

各ページに以下を含める:
- `Course` — PADIオープンウォーターダイバーコース
- `BreadcrumbList` — ホーム > [地域名]でダイビングライセンス取得
- `FAQPage` — ページ内のFAQ全問
- `LocalBusiness` — 三浦 海の学校（共通）

## meta タグテンプレート

```html
<title>[地域名]でダイビングライセンスを取るなら｜三浦 海の学校【PADI公認】</title>
<meta name="description" content="[地域名]からダイビングライセンス（Cカード）を取得するなら三浦 海の学校。PADI公認5スターIDCセンター。[地域からの所要時間]、専用プール完備、少人数制で初心者も安心。">
<meta name="keywords" content="ダイビングライセンス [地域名],[地域名] ダイビングライセンス,PADI ライセンス [地域名],ダイビング Cカード [地域名]">
<link rel="canonical" href="https://miura-diving.com/[slug]/">
```

## 内部リンク設計

```
[地域ページ]
  → /license/（全コース一覧）
  → /owd-license/（OWD詳細）
  → /fun-diving/（ライセンス取得後の楽しみ）
  → /beginner-guide/（初心者ガイド）
  → /contact/（お問い合わせ）

/license/（フッター）
  → [地域ページ]
```
